## How to add a new post

1. Create a new file in `content/blog/`, named `your-post-slug.mdx` — the
   filename becomes the post's URL (`/blog/your-post-slug`).
2. Start it with a `metadata` export like the one at the top of this file:
   `title`, `date` (`YYYY-MM-DD`), `excerpt` (shown on the blog list page),
   and `tags` (optional).
3. Write the rest of the post in Markdown below the metadata block —
   headings, **bold**, _italics_, lists, [links](/blog), images, and
   blockquotes all work.
4. Commit the new file and deploy — no other code changes needed.

## Markdown quick reference

- Headings: `#`, `##`, `###`
- Lists: `- item` or `1. item`
- A link: `[Ming Chuan University](https://www.mcu.edu.tw/)`
- An image: `![alt text](/blog/your-image.jpg)` (put images in `public/blog/`)

> Blockquotes look like this — good for pulling out a quote or a highlight
> from the day.
